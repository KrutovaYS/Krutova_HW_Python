Инструкция для НАСТАВНИКА

1. Необходимо создать файл .env в папке с проектом и записать туда свои логин/пароль от YouGile:

text
YOUGILE_LOGIN=твоя_почта@mail.ru
YOUGILE_PASSWORD=твой_пароль

2. Запуск тестов

pytest test_yougile.py -v

Важно!

Токен создастся автоматически при первом запуске и сохранится в yougile_token.json
При повторных запусках тесты будут использовать сохранённый токен

Примечание:

Создан отдельный файл с классом авторизации yougileAuth.py для того, чтобы не расходовать лимит создания ключа.
