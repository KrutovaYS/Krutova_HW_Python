# Домашняя работа: Автоматизация тестирования (урок 10)

## Описание проекта

В данной папке находятся два независимых тестовых проекта:
1. **Тестирование интернет-магазина SauceDemo** — проверка авторизации, добавления товаров в корзину и итоговой стоимости
2. **Тестирование калькулятора** — проверка вычислений с задержкой

Оба проекта реализованы с использованием **Page Object Model**, **pytest** и **Allure** для формирования отчетов.

---

## **Проект 1: Тестирование SauceDemo**

### Что проверяет тест:
- Авторизация на сайте под стандартным пользователем (`standard_user`)
- Добавление трех товаров в корзину:
  - Sauce Labs Backpack
  - Sauce Labs Bolt T-Shirt
  - Sauce Labs Onesie
- Переход в корзину и нажатие Checkout
- Заполнение формы с персональными данными
- Проверка итоговой стоимости заказа (ожидается `$58.29`)

### Структура Page Object для магазина:
| Файл | Назначение |
|------|------------|
| `page_shop/AuthPage.py` | Страница авторизации |
| `page_shop/MainPage.py` | Главная страница (каталог товаров) |
| `page_shop/CartPage.py` | Страница корзины |
| `page_shop/InputFormPage.py` | Страница ввода данных |

### Тестовый файл:
- `test_shop.py` — тест для магазина

---

## **Проект 2: Тестирование калькулятора**

### Что проверяет тест:
- Открытие страницы калькулятора
- Установка задержки отображения результата (45 секунд)
- Выполнение операции: 7 + 8
- Ожидание появления результата
- Проверка, что результат равен 15

### Структура Page Object для калькулятора:
| Файл | Назначение |
|------|------------|
| `page_calc/calc_main_page.py` | Главная страница калькулятора |

### Тестовый файл:
- `test_calc.py` — тест для калькулятора

---

## **Общая инструкция по запуску тестов**

### 1. Установите зависимости

```bash
pip install selenium webdriver-manager pytest allure-pytest

2. Убедитесь, что браузеры Firefox и Chrome установлены
Тесты используют браузеры Firefox и Chrome. Убедитесь, что они установлены на вашем компьютере.

3. Запустите тесты
bash
# Запустить все тесты в папке
pytest -v

# Запустить только тест для магазина
pytest test_shop.py -v

# Запустить только тест для калькулятора
pytest test_calc.py -v
4. Запуск с генерацией Allure-отчета
bash
# Запустить тесты и сохранить результаты
pytest --alluredir=./allure-results -v

# Просмотреть отчет
allure serve ./allure-results
Что отображается в Allure-отчете

Для теста магазина:
Название: Тест на авторизацию, добавление товаров в корзину и проверку итоговой суммы
Описание: Проверка работы корзины на сайте SauceDemo

Шаги:

Создание экземпляра страницы Авторизации
Открытие сайта
Ввод логина и пароля
Добавление товаров в корзину
Переход в корзину и Checkout
Заполнение формы
Проверка итоговой суммы ($58.29)

Для теста калькулятора:
Название: Тест калькулятора: 7 + 8 = 15
Описание: Проверка работы калькулятора с задержкой 45 секунд

Шаги:

Открытие страницы калькулятора
Установка задержки
Нажатие кнопок 7, +, 8, =
Ожидание результата
Проверка результата (15)
